# Space-Defender

Space Defender game on Unreal Engine for Game Development course
A mobile tower-defense/shooter game, made on Unreal Engine 5.8 with Blueprints.



This game has:
Custom touch joystick, clickable menus, and HUD.
HUD - adapts to the screen size and includes safe zone.
Shooting and reloading mechanic. 
Three different enemies - Walker, Speedster, Flyer.
Three levels - Tutorial, Boss, Endless - with different goals - survive for a set period of time or get as much score as possible.
Saving progress system.
